Python is a high-level, interpreted and general-purpose programming language created by Guido van Rossum and first released in 1991. It is known for its clear, readable syntax and dynamic typing, which makes it easy for beginners to learn.

Python is the most popular language for artificial intelligence and data science because of libraries such as NumPy, pandas, scikit-learn, TensorFlow and PyTorch. It supports object-oriented, procedural and functional programming styles.
